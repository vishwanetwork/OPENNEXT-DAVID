## Data contract

- Keep `provider`, upstream seller (for aggregators), region/AZ, instance SKU, GPU model, physical GPU count, rental type, currency, billing unit, raw amount, source URL, observed time, and effective time. Missing prices and unavailable capacity are not zero.
- Normalize GPU comparisons only when the complete allocation is known: instance-hour price / physical GPU count. CPU, memory, disk, networking, tax, subscriptions, and upfront commitments must remain explicit rather than silently included/excluded.
- Do not turn a current snapshot into invented historical curves. Store observations going forward; use provider history only where officially documented. Reserved prices require term/payment-option/upfront cost, not just a discounted hourly number.
- Separate public retail, authenticated account/contract prices, and aggregator quotes. Shadeform prices are Shadeform's offers, not proof of another provider's direct account pricing.
- Price ingestion performs read-only requests only. A read-only quote may use POST/GraphQL; no create, launch, purchase, bid, reserve, or delete actions belong in a collector.

## Identity distinction: Packet.ai versus Equinix Metal

Do not mark Packet.ai retired because it shares the word Packet. The **former Packet / Equinix Metal** service is a different business: official Metal documentation states service ended 2026-06-30 and resources were removed from 2026-07-01. If legacy Metal is added as its own provider, show it as retired and do not schedule catalog ingestion. [Official Equinix Metal lifecycle](https://docs.equinix.com/fr/metal/?_i18n_attempted=1).

## Operational acceptance checks

1. Configure credentials through server environment/secret storage only. Rotate any credential previously pasted into chat/images before production use; the documentation contains no key values.
2. Test with read-only list/quote calls; capture redacted HTTP status, schema/version, source timestamp, currency and coverage gaps.
3. Follow every documented page token/link; mark any capped/truncated run `completed_with_gaps`, not `completed`.
4. Preserve a last-known-good catalog after a failed run while exposing stale status. Never replace it with demo/random prices.
5. Build Terminal queries from the backend's normalized observations and expose their provenance. AWS Spot stays `credentials_required` until the user supplies an IAM Role/default credential chain; AWS public On-Demand must remain usable independently.
